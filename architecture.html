アーキテクチャ

Spring Boot内部の責務分離と、AWS EC2に配置するコンテナ構成を分けて説明します。

アプリケーションの処理

HTTPリクエストからDBアクセスまで、各層の責務を分けます。

01BrowserHTTPリクエスト
02Controller入力受付・画面制御
03Service / UseCase業務ロジック
04RepositoryJPA / SQL
05MySQL永続化
画面表示ではControllerがModelを渡し、JSPからHTMLを返します。

AWSへの配置計画

PUBLIC INTERNETブラウザからHTTPSでアクセス
AMAZON EC21インスタンス / Amazon Linux 2023
01 · 追加予定NginxHTTPS・リバースプロキシ
02 · アプリSpring BootJava 17 / 実行可能WAR
03 · DBMySQL 8外部非公開 / Docker volume
Docker Compose によるコンテナ管理

今回の方針ではRDS・ALB・NAT Gatewayは採用しません。Nginx・HTTPSを含む本番公開は未確認です。

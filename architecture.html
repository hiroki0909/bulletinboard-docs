システム設計

アプリケーション内部とAWS上の配置を別々に示す。今回の計画はEC2 1台に複数コンテナを配置する構成。

アプリ内部の処理フロー（詳細）

リクエストとレスポンスの流れ
ブラウザHTTPリクエスト
→
ControllerURLと入力を受け取る
→
Service / UseCase業務処理
→
RepositoryJPA / SQL
↳ RepositoryがMySQLにアクセス → ControllerがModelを渡す → JSPがHTMLを描画 → ブラウザへ返却

Spring BootWAR + 組み込みTomcat
→
MySQL 8内部通信 / 永続Volume

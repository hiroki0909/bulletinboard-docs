AWS のロゴは AWS の**ブランドロゴ**です。個別サービスである EC2 の公式アーキテクチャアイコンではありません。AWS の正式なアーキテクチャアイコンは [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/) を参照してください。

PROJECT OVERVIEW

掲示板システム

JavaとSpring Bootを用いたユーザー登録・投稿・コメント機能を備えるWebアプリケーション。Dockerによる実行環境の統一とAWS EC2へのデプロイを進めている。

ひと目で分かるプロジェクト

Webアプリ

Spring Boot / Spring MVC / JSP

データ管理

MySQL 8 / JPA / Flyway

実行・公開

Docker Compose / AWS EC2

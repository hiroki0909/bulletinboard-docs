SECURITY

セキュリティ設計

アプリケーションの認証・認可と、AWS／Dockerの公開範囲を分けて考える。

アプリケーション側

認証・認可

Spring Securityの設定、投稿・コメントの操作権限を確認する。

CSRF / XSS

フォームのCSRF対策と、JSP出力時の適切なエスケープを確認する。

パスワード

BCrypt等のハッシュ化、ログ・画面への秘密情報漏えい防止。

登録フロー

トークンの期限・一回限りの利用・メールアドレス検証を点検する。

インフラ側

対象基本方針
MySQL 3306ホストへポート公開せず、Compose内部ネットワークで接続
Adminer必要時のみ起動し、原則ループバックに限定
Spring Boot 8080当面ループバックに限定し、公開時はNginxを経由
HTTPSNginxとTLS証明書を設定予定
シークレットソース・Composeに直書きしない。Gitに含めない
